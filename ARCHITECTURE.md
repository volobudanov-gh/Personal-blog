## 🎯 Цель проекта

### Основная цель
- Создать персональный блог-презентацию на **испанском языке**
- Показать себя таким, какой я есть на самом деле
- Найти партнера (парня) для создания семьи

### Целевая аудитория
- Потенциальные романтические партнеры
- Люди с совпадающими интересами и ценностями

### Основные функции
1. **Профиль** - статическое описание Voldy с данными
2. **Блог** - статьи и публикации (публичные и приватные)
3. **Тест совпадения** - определение совместимости с посетителями
4. **Админ-панель** - управление контентом (только для автора)

## 🛠️ Технический стек

### Frontend
- **Next.js 14+** - React фреймворк с SSR/SSG
- **TypeScript** - типизированный JavaScript
- **Tailwind CSS** - утилитарный CSS
- **React** - компоненты UI

### Backend
- **Supabase** - Firebase альтернатива
  - PostgreSQL база данных
  - REST API (автоматически генерируется из таблиц)
  - Аутентификация (Supabase Auth)
  - Хранилище файлов (Storage)
  - Real-time подписки (опционально)

### DevOps & CI/CD
- **GitHub** - версионирование кода и миграций
- **Vercel** - хостинг Next.js приложения
- **GitHub Actions** - автоматизация (опционально)

### Языки
- **Испанский** - для блога и пользовательского контента
- **Английский** - для админ-панели и системных сообщений

### Планируемые таблицы (🔄 будут созданы)

#### `posts`
Статьи и посты блога.

```sql
CREATE TABLE posts (
  id BIGSERIAL PRIMARY KEY,
  title TEXT,
  content TEXT,
  category TEXT,
  is_public BOOLEAN,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```

#### `test_questions`
Вопросы для теста совпадения интересов.

```sql
CREATE TABLE test_questions (
  id BIGSERIAL PRIMARY KEY,
  question_es TEXT,
  question_en TEXT,
  type TEXT, -- 'yes_no', 'multiple_choice', 'scale'
  options JSONB,
  category TEXT,
  order INTEGER
);
```

#### `test_results`
Результаты пройденных тестов посетителями.

```sql
CREATE TABLE test_results (
  id BIGSERIAL PRIMARY KEY,
  user_name TEXT,
  email TEXT,
  answers JSONB,
  score INTEGER,
  created_at TIMESTAMP
);
```

#### `photos`
Фотографии профиля.

```sql
CREATE TABLE photos (
  id BIGSERIAL PRIMARY KEY,
  profile_id BIGINT,
  photo_url TEXT,
  is_main BOOLEAN,
  order INTEGER,
  uploaded_at TIMESTAMP
);
```

## 👨‍💻 Как работать с Claude

### Принципы работы

#### 1. **Шаг за шагом, без спешки**
- Не спешим с добавлением всех функций сразу
- Завершаем одну фазу перед следующей
- Проверяем результат перед продолжением

#### 2. **Ясность и точность**
- Описываем проблему/задачу подробно
- Задаём уточняющие вопросы если что-то непонятно
- Говорим "хватит" когда нужна пауза

#### 3. **Документирование**
- Каждый важный шаг записывается
- Архитектурные решения объясняются
- Обновляем этот документ при изменениях

## 📝 Примечания

### Почему такая архитектура?

1. **Next.js** - SSR/SSG для лучшей SEO, удобство разработки
2. **Supabase** - легко масштабировать, встроенная аутентификация, real-time возможности
3. **Vercel** - идеален для Next.js, автоматический CI/CD
4. **GitHub** - версионирование миграций БД важно

### Безопасность

- Приватный кабинет будет защищён Supabase Auth
- Service Role Key хранится только на сервере (backend)
- Anon Key используется на фронтенде (ограниченные права)
- Данные пользователей (email, результаты тестов) не экспортируются

### Масштабируемость

Архитектура позволяет легко:
- Добавить больше постов и статей
- Расширить тест новыми вопросами
- Добавить комментарии, рейтинги
- Интегрировать социальные сети
- Запустить мобильное приложение
